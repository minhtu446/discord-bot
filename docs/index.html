🌐XX. Multi-Guild Support ▼
Đã hỗ trợ multi-guild hoàn toàn
  • Data files setupChannels/userChannels/userTickets phân guild (key là guildId)
  • DM Relay: Bot tìm server user là member -> forward về server đó
  • Auto scan badwords: Quét tất cả servers khi start
  • Startup log: Gửi đến tất cả servers có kênh log
  • RoleEmoji: Quét tất cả guilds (init + interval 2 phút)
  • Slash commands: Global (hoạt động mọi server)
  • Settings/Config: Lưu theo guildId
  • Bad words: Lưu theo guildId (file text), không có global fallback
  • Migration tự động: Detect format cũ -> convert sang guild-scoped
⚠️XXI. Limitations & Blocked ▼
GitHub Actions free tier: 6h/session hard limit -> gap ~2-3 phút khi restart
EasyOCR crash: Python process hay crash exit code 3221225786 — đã thêm circuit breaker + exponential backoff
Pinterest/9gag/Reddit/JustMeme API: Không dùng được làm meme source (bị chặn / không trả ảnh trực tiếp)
"Tương tác không thành công": Khi bấm nút lúc bot restart mid-interaction
Discord rate limit: Presence updates ~5 lần/20 giây — đã tăng lên 10s
